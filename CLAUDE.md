# CLAUDE.md

**[AGENTS.md](AGENTS.md) is the conventions file.** Read it before writing code —
invariants, layout, style, testing, config, task tracking, versioning and commits
all live there.

This file exists only so the conventions are found automatically. It deliberately
holds no rules of its own: two files of conventions drift, and then the question
"which one is right" has no answer.

Also read, at the start of a session:

- [TASKS.md](TASKS.md) — what to build next. Update it at the end of a session.
- [docs/handover.md](docs/handover.md) — how the built parts fit together, and
  which traps have already cost someone a session.
