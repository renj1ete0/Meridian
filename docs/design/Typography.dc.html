Why this pair
Archivo was drawn for signage and small-size print — open apertures, a tall x-height, weight that holds at 12px. It is a wayfinding face, which is the right register for a system about reference lines and bearings. It replaces Space Grotesk here: same technical family, without the 2021 startup accent.
IBM Plex Mono was drawn for engineering documentation. It carries humanist detail into a monospace, so a column of confidence values and source domains stays warm rather than clinical — and its true italic gives hedged quotations somewhere to live.

In use
The split is strict: Archivo carries anything written for a reader, Plex Mono carries anything the system measured. A source domain, a confidence value, a tier, a timestamp, a chunk id — all mono, so provenance is recognisable before it is read.
Uppercase is reserved for mono labels at 10px with 0.15em tracking. Archivo is never set in caps.
